🚀 Getting Started

1️⃣ Download the application

Visit this link to download the application. Make sure to download the latest release file.

2️⃣ Run the application

After downloading, double-click the .exe file to launch the program. Windows may show a security prompt - this is normal. Simply click "More Info" then "Run Anyway" if you receive a SmartScreen warning.

3️⃣ Right-click your installer

Navigate to your installer file (.exe, .msi, or .msp). Right-click on it, and you'll see the new context menu option "Prepare for Intune" or similar. Click it.

4️⃣ Watch the magic happen

The tool will process your file and generate the folder structure and .intunewin package. You'll see on-screen confirmation of what was created, including:

Output folder created: C:\IntunePackages\MyApp\ Detection rule: MSI Product Code {1234-ABCD-5678-EFGH} Install command: msiexec /i MyApp.msi /qn Architecture: 64-bit

That's exactly the information you'll copy into the Intune portal when adding a new Windows line-of-business app.

💡 Pro Tips for Best Results

Tip 1: Always use the latest stable version of your installer. Avoid beta or preview builds - they're more likely to cause Intune deployment issues.

Tip 2: Save your packages to a centralized folder. You'll need to reference the same file paths when configuring deployments.

Tip 3: If you're deploying through Intune, remember to test on a small pilot group first. The tool gives you a solid foundation, but every environment is unique.

Tip 4: Keep your Windows system updated. This tool works best on Windows 10 version 1903 or newer, and all versions of Windows 11.

❓ Frequently Asked Questions

Q: Do I need administrator rights to use this tool?

Yes, you'll need admin permissions on your machine to modify context menus and access the necessary folders. The tool itself is simple to run.

Q: Does it work with all installer types?

The tool supports standard Windows installers: .exe (custom installers), .msi (Microsoft Installer), and .msp (Microsoft Installer Patch).

Q: Can I edit the generated rule if needed?

Absolutely! The tool creates a great baseline, but you can always adjust detection rules, commands, or architecture in the Intune console if your environment requires special handling.

Q: Is my data sent anywhere?

No. All processing happens locally on your computer. No internet connection is required beyond the initial download.

🛠️ Troubleshooting

Issue: Context menu option doesn't appear

Restart Windows Explorer (right-click the taskbar, select Task Manager, find Windows Explorer, right-click, restart). If still missing, try running the tool as administrator once.

Issue: Anti-virus warning

Some security software may flag packaging tools. You can safely allow this application if you downloaded it from the official releases page linked above.
